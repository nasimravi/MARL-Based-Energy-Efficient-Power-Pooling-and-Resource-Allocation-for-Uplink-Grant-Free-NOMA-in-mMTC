# MARL-Based-Energy-Efficient-Power-Pooling-and-Resource-Allocation-for-Uplink-Grant-Free-NOMA-in-mMTC
This repository contains the MATLAB code for the paper titled `MARL-Based Energy-Efficient Power Pooling and Resource Allocation for Uplink Grant-Free NOMA in mMTC` published in IEEE Internet of Things Journal. The manuscript is available on https://ieeexplore.ieee.org/abstract/document/11541043
